# Expense Tracker

An intuitive and easy-to-use expense tracking web application built with the **MERN stack** (MongoDB, Express, React, Node.js) for managing and keeping track of personal or business expenses.

## Features


- **Expense Management**: Add, update, and delete expenses with various categories.
- **Dashboard**: View expenses in a user-friendly dashboard with detailed graphs and charts.

- **Search and Filter**: Easily search and filter expenses based on categories and dates.

## Technologies Used

- **Frontend**: React, Tailwind CSS, Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
